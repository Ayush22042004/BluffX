# v0.3.0 UI follow-up - setup polish and beta identification

Date: 2026-11-13. Package version remains `0.3.0`. Implemented locally; not deployed.

This update follows the user's new request to identify the game as beta. It supersedes the earlier preference to remove all beta wording, while keeping the full-width development warning strip removed.

## Changes

- Create Room and AI setup use aligned two-column desktop fields and a single-column mobile layout, clearer label/hint sizes, quieter panel borders and more restrained selected states.
- Player/name and preset/mode controls are grouped together; decks and turn duration share a row. Native dropdowns fill their columns instead of appearing as narrow, unfinished controls.
- Table voice is a labeled checkbox card with an aligned control and an explanation of opt-in microphone behavior. AI style help is displayed separately from its selector.
- Deck recommendations use the actual AI participant count on the AI setup screen and capacity on multiplayer setup. Explicit deck choices remain unchanged.
- The existing logo now has a small **BETA v0.3.0** identifier on the login and application headers. Its version comes from the client build configuration; its tooltip explains that BluffX is still in beta.
- A desktop notification recommends fullscreen with **F11** (Control-Command-F guidance on Mac). It appears on each new page load and refresh, can be dismissed, and closes automatically after twelve seconds. Dismissal is not persisted. It does not force fullscreen or intercept the browser shortcut.
- Mobile/touch-only screens do not receive desktop keyboard guidance. No backend/gameplay rules, database migrations, credentials or deployment settings changed.

## Verification

`npm run build` passed. Eight browser tests passed across the new display-hint checks, reconnect regressions and responsive layout audit. Audited widths: 360, 390, 768, 1024, 1366 and 1920 pixels, with no audited horizontal overflow/panel collisions. The new tests verify that dismissal followed by refresh restores the recommendation, the version badge appears, mobile omits the F11 prompt and the voice checkbox remains operable/aligned.

The earlier v3 feature browser checks also passed six of seven cases during the first run; the old assertion forbidding any beta text was updated to match the user's new instruction, and the final targeted run passed all eight cases. Screenshots were inspected locally. No production deployment was performed.
