# v0.3.0 clear speaking indicators

Date: 2026-11-13. Local visual update; not deployed. Version remains 0.3.0.

The Players list now highlights the active speaker with a green row accent, avatar ring and a labeled Speaking badge with a small waveform. Readiness, cards, host and turn indicators remain visible. Table seats also receive the avatar ring. Table Voice replaces the generic Mic on status with the same Speaking badge during detected speech and highlights the member row.

Reuses existing local speech detection and its 1.2-second hold. `VoiceChat` publishes room-scoped seat IDs to its parent only when the detected speaker set changes; there are no extra Socket.IO events, database writes, timers or microphone changes. Mute, leave, roster replacement, disconnect and room cleanup clear the published activity. Indicators reflect locally available voice streams for clients joined to voice, not a new global presence service. Muted participants are excluded immediately from the published set.

Added shared `SpeakingBadge.jsx`; updated `VoiceChat.jsx`, `App.jsx`, CSS and real-voice regression assertions. Waveform animation honors reduced-motion settings. No environment settings, schema, dependency or game-rule changes.

Verification: lint and production build passed. `npm --prefix client run test:e2e -- voice.spec.js ui-layout.spec.js` passed all five tests, checking sender/receiver player highlights, muted listener exclusion, clearing after mute, 120 playback samples with zero silent samples and responsive layouts. Desktop Players and Table Voice screenshots were visually inspected.

Cosmetic follow-up, 2026-11-13: added the missing gear path to the shared Settings icon, replacing its fallback card symbol in the utility rail. The Table settings heading uses the same gear. No behavior changed; lint/build verification accompanies this edit.
