# v0.3.0 neon blue theme update

Date: 2026-11-13. Package version remains 0.3.0. Local implementation; not deployed.

Replaced pink/purple interface accents with neon blue across navigation, login, setup, gameplay, cards, chat, voice, social drawers and profile controls. Dark surfaces now use navy tones, with cool text and blue focus/selection/glow treatments. Scenic lounge backgrounds use a blue luminosity blend without changing the original artwork files, player portraits or uploaded avatars. The existing ICO logo remains in use with a display-only hue adjustment.

Red card suits, authentication errors, gold warnings and green presence indicators retain their distinct meanings. Existing layout, beta/version labels, fullscreen guidance, animations and gameplay behavior are preserved.

Files: `client/src/index.css`, `client/src/components.jsx`. No dependencies, environment settings or database migrations added. Existing uncommitted Resend work is independent of this visual update.

Verification: `npm run build` passed. `npm --prefix client run test:e2e -- display-polish.spec.js ui-layout.spec.js auth.spec.js` passed all 8 browser tests, including login, setup, profile, lobby and six-player game layout checks at widths 360–1920 pixels. Audited screens reported zero horizontal overflow, clipped panels or sidebar collisions. The desktop setup screenshot was visually inspected. No production deployment performed.
