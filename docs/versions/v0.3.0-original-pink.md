# v0.3.0 original Pink restoration and stronger theme identities

Date: 2026-11-13. Local visual update; not deployed. Version remains 0.3.0.

Restored the original v3 pink/purple color declarations from repository revision `409cb84`, mapped through theme variables. Pink retains the original hot pink, purple, rose and gold families, warm amber lounge artwork, crimson brand X, richer gradients and neon home cards. Theme-picker functionality and saved choices remain compatible; Blue stays the default.

Blue now distinguishes electric blue primary actions, violet secondary actions and cyan tertiary details on navy. Emerald combines green, teal and copper on dark forest surfaces. Home tiles have separate colored gradient fills, borders, icons and glow; setup actions and social controls use complementary accents. The picker previews each combination.

Changed `index.css`, `theme-colors.css`, `theme-palettes.css`, and `Preferences.jsx`. Original red card suits/authentication errors are explicitly preserved. No database changes, dependencies, environment settings or production deployment.

Verification: production build and release checks passed. `npm --prefix client run test:e2e -- themes.spec.js ui-layout.spec.js` passed all six tests, covering saved themes, invalid-value fallback and layouts from 360–1920px including six-player gameplay. No overflow, clipped panels or sidebar collisions were reported. Screenshots for Pink, Blue and Emerald were visually inspected. Unused converted color tokens were removed to avoid shipping redundant palettes.
