# v0.3.0 Resend report notifications

Date: 2026-11-13. Package version remains 0.3.0. Local implementation; not deployed.

Manual reports now queue optional support emails in PostgreSQL, in the same transaction as report storage. A bounded worker leases jobs, retries with a stable Resend idempotency key, resumes after restart, and records provider acceptance separately from delivery. Automatic diagnostics do not send email. Existing verification, reset and deletion mail flows reuse the same mailer.

Main changes: `server/src/report-email.js`, `mailer.js`, `launch-controls.js`, `index.js`, `auth.js`, `database.js`; configuration in `server/.env.example` and `render.yaml`; CLI `server/scripts/check-email.js`; player-facing report privacy copy in `client/src/LaunchTools.jsx`. Added unit, HTTP and real PostgreSQL outbox tests. Test preload files explicitly disable real report recipients.

Additive migration: `006_report_email.sql`, with private outbox, scheduling/budget indexes, and cascading report retention. Existing migrations/accounts/results are preserved. Applied only to the isolated test database during verification. Production still requires review of all pending migrations and the existing single-owner handoff.

New settings: optional `REPORTS_TO`, `REPORT_EMAIL_MAX_DAILY=20`, `REPORT_EMAIL_INTERVAL_MS=60000`. No new paid infrastructure or dependencies. See [complete setup and limits](../resend.md).

Verification: focused unit/HTTP checks passed (11 tests). Real PostgreSQL outbox suite passed (9 including its parent), covering rollback, concurrent workers, restart, uncertain provider acknowledgement, daily cap, bounded retries, idle scheduling and private operator statuses. Provider calls were simulated; no live email delivery is certified. Full release checks are recorded in the accompanying implementation report.

Outstanding: configure the private API key and owner inbox, run the explicit single-email test, verify inbox receipt, and verify an owned sending domain before public account email delivery. No bounce/inbound mail processing is included. No production deployment or data reset was performed.

Final local checks: `npm test` passed 97 tests, with 6 opt-in suites skipped and zero failures; `npm run build` and `npm run check:release` passed. `npm run test:e2e -- --project=chromium auth.spec.js launch.spec.js` passed all 6 browser tests on isolated test ports. `npm run check:email` correctly reported local mode and missing API key/report inbox, without sending mail. The isolated PostgreSQL outbox suite is run separately with `node --require ./server/test/real-db-env.cjs --test server/test/report-email-pg.test.js`.
