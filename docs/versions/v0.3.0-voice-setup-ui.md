# v0.3.0 voice setup selector polish

Date: 2026-11-13. Local UI update; not deployed. Version remains 0.3.0.

Replaced the native audio-mode dropdown with two themed radio cards: Headphones / Natural voice and Speakers / Echo protection. Each option has a distinct icon, selected border and native radio state; labels and descriptions are separated to eliminate corrupted separator characters and operating-system dropdown styling. The compact two-column layout fits the voice sidebar and mobile screen, with visible keyboard focus.

Audio capture rules are unchanged: Headphones is default, Speakers enables echo cancellation, mode changes are allowed only while muted, and the saved preference remains browser-local. Disabled options preserve the selected mode clearly without implying an interrupted connection. All three themes use their existing palette roles.

Files: `client/src/VoiceChat.jsx`, `client/src/index.css`, selector references in `client/tests/voice.spec.js`. No dependencies, server/game changes, environment settings or migrations. Production build and lint passed. The real two-browser voice regression passed, including controls inside the panel at 390/1024/1366px, both capture modes and 120 playback samples with zero silent samples.

## Volume slider follow-up — 2026-11-13

Extended the existing real-voice browser test with pointer clicks at both ends, keyboard Home/End checks and exact audio element volume assertions for 0%, 100% and 35%. Lint, production build and this regression passed, with 120 playback samples and zero silent samples.
