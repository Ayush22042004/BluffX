# v0.3.0 Brevo transactional email alternative

Date: 2026-11-13. Local implementation; not deployed. Version remains 0.3.0.

Added Brevo HTTPS delivery alongside existing Resend, SMTP and local previews. Verification/reset/deletion/report flows reuse their existing shared mail service. `MAIL_PROVIDER=brevo` requires backend-only `BREVO_API_KEY` and a verified `MAIL_FROM`; the Render blueprint now selects Brevo. No SMTP ports, frontend secret, new dependency or database migration.

The adapter validates addresses, uses a timed HTTPS request without redirects, strips raw provider errors and translates stable report keys into Brevo UUID idempotency keys. It recognizes documented duplicate acknowledgements without claiming inbox delivery. `auto` prefers Brevo if both provider keys exist; explicit provider selection is recommended.

Report payloads now pin their provider. Provider changes and expired provider dedupe windows stop uncertain automatic sends while retaining the original report. Brevo retries are conservatively limited to 25 minutes within its documented 30-minute window; Resend's existing longer window is preserved. No automatic cross-provider resend or production queue rewrite.

Updated `mailer.js`, `report-email.js`, email-check CLI, backend environment template and Render blueprint. Added Brevo adapter tests and extended real PostgreSQL outbox tests for shorter retry windows, provider changes and successful Brevo acceptance. See [setup guide](../brevo.md). Verification results are appended after completion. Live delivery requires the user's account setup and is not claimed by simulated tests.

Verification: the isolated PostgreSQL report suite passed all ten tests, including provider-window expiry and no cross-provider resend. The account-route integration exercises the real Brevo adapter with injected HTTP responses through signup verification, password reset/login and account-deletion confirmation. Build, lint and release checks passed. Default `check:email -- --provider brevo` sends nothing and currently reports the Brevo key missing, with app mail still in local mode. No real email was sent or production setting changed. Full unit results are recorded in the final implementation report.
